# Evidence — CMC attested-TLS channel binding spike

Evidence for the spike that pins the CMC attested-TLS library, wraps it behind the
`internal/atls` package and proves the channel binding end to end on the target cluster.

Every artefact here is regenerated by the scripts next to it; nothing in this folder is edited by
hand. Private keys never land here — only certificates, reports, logs and verdicts.

## Scope

| Pinned library | `github.com/Fraunhofer-AISEC/cmc` **v0.9.15** (commit `6754d3c`) |
|---|---|
| Wrapper | `internal/atls` — the only package allowed to import CMC |
| Attestation model | one `cmcd` per zone, reached over gRPC; `libapi` (in-process CMC) for tests only |
| Evidence | CMC software driver (`sw`) — mock evidence, no TEE hardware |
| Binding | RFC 9266 TLS exporter (`EXPORTER-Channel-Binding`), report nonce = `sha256(exporter ‖ prover leaf cert)` |

## Layout

| Folder | Proves | Contents (expected) |
|---|---|---|
| `criterion-1-mutual-handshake/` | Two processes complete a mutually attested handshake and derive identical binding material | `session.json` per end (exporter, derived nonces, verdict), handshake logs |
| `criterion-2-tampered-binding/` | A tampered binding aborts the handshake | output of the relay (MITM) test and of the nonce-tampering proxy, with the error each end returns |
| `criterion-3-session-loss/` | Killing either side mid-session produces recorded re-establishment behaviour and error surfaces | `reconnect-findings.md` (per scenario: error, time to detect, reconnect behaviour) and logs |
| `criterion-4-wrapper-isolation/` | No package outside the wrapper imports CMC types; the interface is frozen | `depguard` run output, frozen interface description |

The pin itself is recorded in the architecture decision record `docs/adr/0010-…`.

## Status

and target-cluster runs are kept apart; only target-cluster runs close a criterion.
